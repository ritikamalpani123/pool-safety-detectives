# Pool Safety Detectives

Bilingual water safety game for children ages 5–9.

**Ritika Malpani — Creator & Producer**

Play: https://ritikamalpani123.github.io/pool-safety-detectives/

The single `index.html` contains all five illustrations and all 36 English and Spanish narration MP3s. Playing does not call OpenAI or require an account. No API keys or backend are used.

## Update the game

Keep the latest standalone HTML as `index.html`. Replace it in this repository, commit the change to `main`, and GitHub Pages republishes automatically. Keep `.nojekyll`. Updates may take several minutes. You can ask Codex to prepare, test and upload future versions.

## Hosting

GitHub Pages publishes `main` / root with HTTPS. The public repository and default github.io address use GitHub Free, subject to GitHub usage limits. No paid domain, server, AI subscription or API calls are required for visitors.

The game is educational and does not replace active adult supervision.
